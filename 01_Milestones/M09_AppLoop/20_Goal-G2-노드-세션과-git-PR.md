## 목표

G1 실행기의 포트(명령·git·gh·fs·세션)에 실물 구현이 붙는다. 작업 노드는 앱 「자동」 모드의 Agent SDK 세션으로 돌고, 그 세션은 원격 쓰기와 `.agentdeck/` 쓰기를 잠금 노드에 거부당한다. 원격은 실행기 코드만 만진다. 실제 git(임시 저장소와 로컬 bare 원격)으로 goal 하나가 브랜치에서 마일스톤 브랜치 병합까지 가는 것을 시험한다.

## 범위

- **만들 것**
  - 자격 없는 자식 환경 — 명령 포트와 작업 노드 세션이 쓰는 환경. 변수(`GH_TOKEN` 등)만 빼는 것이 아니라 gh 설정 폴더·git 시스템/전역 설정·자격 도우미·터미널 질의를 끊어, 그 환경에서 `gh auth status`와 `git credential fill`이 자격을 못 얻는 것을 실측한다(진짜 push는 하지 않는다).
  - 실행 상태의 앱 쪽 다이제스트 — 실행기가 `run-state.json`을 쓸 때마다 그 sha256을 앱 영역(작업 저장소 밖)에 적고, `load`·`step`은 다르면 멈추며 한 번 본 불일치는 래치된다. 편집 도구와 순진한 Bash 편집을 잡는 겹이다 — 키 없는 해시라, 세션이 잠금을 피해 앱 영역에 쓰면 짝을 맞출 수 있다(G2 독립 검수 중요 6).
  - 실행기 git 설정 대조 — 실행기는 자격을 가진 채 git을 돌리므로, 연 시점의 로컬·전역 git 설정 스냅숏과 매 호출 직전 대조해 다르면 멈춘다(세션이 심은 `core.fsmonitor`·`filter`·`credential.helper` 등이 자격 있는 프로세스에서 도는 길, G2 독립 검수 차단 1).
  - 실물 포트 — `CommandPort`(위 환경), `GitPort`(git CLI, `ports.ts` 계약 그대로: untracked 포함 통계, rename 두 경로, 병합 실패 시 `merge --abort`, `syncToRemote`), `GhPort`(gh CLI, `findPr`은 열림·병합·닫힘 중 최신, `ciStatus`는 새 머리 검사가 시작 전이면 pending), `FsPort`(작업 저장소 뿌리 밖 경로 거부).
  - 작업 노드 세션 포트 — 노드마다 새 Agent SDK 세션을 기존 `03_Agent` 백엔드로 연다. 지시와 그 노드의 생존 문서만 주고, 권한 모드는 앱 「자동」, 환경은 위의 자격 없는 환경이다. 세션 시간 제한과 취소가 있다.
  - 루프 잠금 노드 — 작업 노드 세션에만 붙는 잠금 판정 노드. git push·원격 브랜치 조작, gh의 PR·병합·저장소·설정 쓰기와 쓰기 `gh api`, 실행기 몫 파일(`.agentdeck/run-state.json`·`verification.md`)의 편집 도구 쓰기를 질문 없이 거부한다. 노드가 쓰는 문서(`milestone-spec.md`, `goals/*.md`)는 막지 않는다. 자동 모드 허용보다 앞에서 판정한다. 명령 글자 판정과 자격 없는 환경은 둘 다 겹일 뿐이다 — 세션이 명령 안에서 환경변수를 되돌리면 OS keyring의 자격이 다시 읽힌다(1차분 실측, 결정 대장). 상태 위조는 앱 쪽 다이제스트가 겹으로 잡고(14행), 원격 쓰기의 구조적 보증은 이 goal 안에 없다.
  - `.agentdeck/`의 git 취급 — 실행기가 작업 저장소의 `.git/info/exclude`에 `.agentdeck/`를 더해 추적 밖에 둔다(저장소 파일을 바꾸지 않고, 체크아웃·병합과 부딪히지 않는다).
  - G1 인계(M09 Backlog 2) — 상태 읽기는 직렬화 줄 밖, 저장소당 실행기 하나(잠금 파일), CI 기다림 상한(넘으면 멈춤).
  - 템플릿을 앱 번들에 싣는 배선 — main이 `program-dev.json`을 읽어 `loadTemplate`에 넘기는 진입점(화면·IPC 연결은 G3).
- **건드릴 곳**
  - 판정 장치(헌법 3조 — 마일스톤 스펙 「건드릴 곳」에 있다): `98_Management/01_GateState/gate-config.json`의 `planPath`(1단계).
  - 판정 장치 밖: `02_Project/00_Source/main/05_Loop/`, `02_Project/00_Source/main/04_Claude/permission/`(잠금 노드 추가), 세션 백엔드를 여는 데 필요한 `main/03_Agent/`·`main/04_Claude/`의 최소 변경, `02_Project/01_TestCode/`, `01_Milestones/M09_AppLoop/`.
- **하지 않을 것**: 화면과 IPC, 사람 게이트 카드, 모델 게이트 실물(G3), 연습 저장소 실주행(G4), 새 의존성, CLI 하네스 변경, 이 저장소에서 원격 쓰기를 하는 시험(시험의 원격은 임시 폴더의 bare 저장소뿐).
- **완료조건**
  - 시험이 실제 git(임시 저장소와 로컬 bare 원격)과 가짜 gh·세션으로 goal 하나를 브랜치 가르기부터 마일스톤 브랜치 병합과 push까지 실행기로 돌린다. 도중에 실행기를 새로 만들어도 이미 된 일을 다시 하지 않는다.
  - 시험이 루프 잠금 노드가 자동 모드에서도 원격 쓰기 명령 꼴들과 실행기 몫 파일 쓰기를 거부하고, 읽기 명령과 노드 문서 쓰기는 막지 않는 것을 본다.
  - 시험이 자격 없는 환경에서 `gh auth status`·`git credential fill`이 자격을 못 얻는 것(동작으로)과, 상태 파일을 밖에서 고치면 다이제스트 불일치로 멈추는 것과, CI 기다림이 상한을 넘으면 멈추는 것을 본다.
  - 하드 게이트 다섯 종 exit 0, `npm test` 실패 0, 독립 검수 반영, goal PR의 `hard-gates` 통과, 정형 절차로 병합.

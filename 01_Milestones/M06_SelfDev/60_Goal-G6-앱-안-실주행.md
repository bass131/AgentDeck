# M06 G6 — 앱 안 실주행 · 앱 안에서 이 저장소의 goal 하나를 어디까지 끝낼 수 있는지 잰다

- 마일스톤: M06 자가 개발 · 작성: 2026-11-17 · 상태: 종결 (PR 65, master `d4f2349e`) · 검증 강도: 약(실주행 — 앱 소스를 고치지 않는다)
- 작업 브랜치: `chore/m06-g6-app-run` — G5 종결 기록 브랜치(`bca217bf`, master `ea6dae8b` 위)에서 갈랐다.

## 목표

CLI를 열지 않고 AgentDeck 앱 안에서 이 저장소의 약 등급 goal 하나를 합의부터 병합 승인까지 실제로 돌린다.
판정은 통과·불통과가 아니라 **사다리 몇 칸까지 갔는가**와 **앱 밖 개입이 몇 번이었는가**로 한다. 이것이 M06 완료선(「앱 안에서 이 저장소의 goal 하나를 합의부터 PR 생성까지 끝낸다」)의 실측이다.

## 범위

- **만들 것**
  - 실주행 무대: 앱 실행용 작업 트리(master 빌드본)와 세션이 여는 작업 트리를 나눈다. 둘 다 이 저장소의 `git worktree`라 실제 GitHub PR이 된다. G1 5절의 리로드 손실은 빌드본 실행으로 피한다(초안 목록의 「작업 트리 분리」를 코드가 아닌 무대 준비로 갈음한다).
  - 실주행 한 번과 측정 보고서(`61_G6-실주행-보고서.md`): 사다리 칸마다 증거(hook-log 줄, `git log`, `gh pr view`, 세션 기록의 사용자 턴), 앱 밖 개입 목록, 막힌 곳.
- **건드릴 곳**: 이 goal 문서, `61_G6-실주행-보고서.md`, `99_Backlog.md`, `01_Work_Pin.md`, `98_Management/01_GateState/gate-config.json`의 `planPath`(1단계), `00_Roadmap.md`. 실주행 안의 goal이 고치는 곳은 그 goal이 정한다.
- **하지 않을 것**
  - 실주행 중 앱 소스 수정. 막힌 곳은 Backlog로 넘기고, 다음 칸으로 가려면 앱 밖 개입으로 세고 기록한다.
  - 병합 승인 카드는 허용하지 않는다(헌법 10조 — 병합은 결정 보드로 따로 받는다). 「항상 허용」은 누르지 않는다(Backlog 11). (처음에는 사람 몫 전부를 사용자가 앱에서 답하게 했으나, 사용자 지시로 메인이 앱을 조작하고 합의·범위 결정은 위임받아 답한다 — 결정 대장.)
  - 메인이 실주행 작업 트리를 편집하지 않는다(관찰만).
- **완료조건**
  - 실주행 한 번이 사다리 끝 칸까지 가거나 처음 막힌 칸에서 멈추고, 칸마다 증거가 보고서에 있다.
  - 앱 밖 개입(사용자가 앱 대신 CLI·탐색기 등으로 한 일, 메인이 대신 한 일)이 모두 세어져 있다.
  - 막힌 곳과 불편이 Backlog 줄로 남아 있다. 사다리가 중간에서 멈추면 이 goal은 닫히지만 M06 완료선은 닫히지 않는다고 보고서에 적는다.

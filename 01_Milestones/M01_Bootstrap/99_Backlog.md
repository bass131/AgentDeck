작업 중에 발견됐지만 그 자리에서 고치지 않기로 한 항목을 모아 두는 표면입니다.
근거는 결정 대장의 [USER] 2026-08-10 규칙입니다 — 계획 밖 변경은 즉시 수정하지 않고 여기로 보고합니다.
항목을 실제로 고칠지, 언제 고칠지는 사용자가 정합니다. 고치기로 하면 워커 태스크로 발행합니다.
지금은 마일스톤 폴더에 두지만, 마일스톤을 넘는 항목이 쌓이면 저장소 수준 표면으로 옮기는 것을 검토합니다.

## 대기 항목

1. **gh·npm 규칙의 정규식 판정 잔존** (Phase 3 관찰) — dangerous-cmd-guard에서 git 계열은 머리 토큰 판정으로 바꿨지만, gh pr·gh release·npm publish 규칙은 아직 정규식이라 판정 방식이 갈립니다. 같은 토큰 방식으로 맞출지 검토가 필요합니다.
2. **partition 픽스처 3종의 커버리지 축소** (Phase 4 관찰) — preview-only·no-tag·no-record 픽스처가 원래 겨눴던 검사(Phase 구획 없음·태그 부재·검증 기록 절 부재)에 닿기 전에, 그 앞 단계인 사람용 개요 검사에서 먼저 반려됩니다. 세 픽스처의 Preview에 「사람용 개요」 절을 넣어야 원래 검사까지 도달합니다.
3. **scanSegments의 인용부 통째 드롭** (Phase 3 관찰) — 현행 가드는 인용부 안 문자를 세그먼트에서 버립니다. 인용문 오탐을 막아 주는 대신, 인용 안에 숨긴 위험 명령도 보지 못하는 트레이드오프입니다.
4. **헌법 2조 문안 명확화** (2026-08-10 해석 확정의 후속) — 루트 CLAUDE.md와 AGENTS.md의 2조에 「새 세션 규율의 대상은 Phase 워커 세션」 문장을 넣는 일입니다. 문안 초안은 있고, 사용자 승인과 워커 편(메인 세션은 루트 파일 편집 불가)이 필요합니다.
5. **모델 라우팅 정책에 Backlog 규칙 반영** — `00_Documents/02_Rules/02_모델-라우팅-정책.md`의 스펙 문법 절에 「계획 밖 변경 금지 — Backlog 보고」 조항을 추가하는 일입니다. 00_Documents 편집이라 워커 편이 필요합니다.

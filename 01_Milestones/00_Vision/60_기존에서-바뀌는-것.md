## 저장소 공개 범위

- 저장소를 비공개로 돌리는 것은 사용자가 GitHub 설정에서 직접 한다.
- GitHub 요금제는 Free다(사용자 확인 2026-11-18). GitHub 공식 문서상 Free의 비공개 저장소에서는 브랜치 보호와 ruleset이 동작하지 않는다. 비공개로 돌리는 순간 `master`의 서버 보호와 필수 검사 `hard-gates`가 병합 조건에서 빠진다. CI 자체는 계속 돌지만 무료 실행 시간에 월 한도가 생긴다.
- 그래서 브랜치를 지키는 장치를 앱 쪽에 구현한다 — 잠금 노드의 `master` 병합 거부, 병합 버튼의 필수 검사 확인, 위험 명령 가드.
- 공개 범위 전환은 앱 쪽 장치가 서버 보호를 갈음할 수 있게 된 뒤에 하는 것이 안전하다(제안).

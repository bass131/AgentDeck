“사람 개입 0회”의 정확한 뜻

무인 실증 세션 안에서 사용자가 방향을 다시 정하거나 오류를 대신 고친 적이 없다는 뜻입니다. 마일스톤 전체에서 사용자가 한마디도 하지 않았다는 뜻은 아닙니다. 사용자 게이트, 즉 사람의 승인이 필요한 지점은 설계대로 4번 열렸으며 모두 승인 기록이 남아 있습니다.

운영 수리 3건

완주에는 영향 없음

Phase 2에서는 파일 이동의 여파로 화면 테스트 3건이 실패해 감독자가 연결 지점을 수리했습니다. Phase 5에서는 사용자에게 안내한 실행 명령이 두 번 연속 틀렸습니다. 첫 번째 명령은 도구 허용 목록이 빠졌고, 두 번째 명령은 인자 순서가 잘못됐습니다. 두 결함 모두 교정한 명령으로 해소했으며, 재발 방지 내용도 기록에 남겼습니다.

설계된 차단 4건

의도대로 작동

역할 게이트는 감독 세션이 소스 코드를 직접 편집하려는 시도를 한 번 막았습니다. 이 게이트는 구현을 워커에게 맡기는 분업 규칙을 지킵니다. 마감 게이트는 요약 스탬프 없이 작업을 끝내려는 시도를 세 번 막았습니다. 네 번 모두 사람이 차단을 풀지 않았습니다. 워커 위임과 스탬프 갱신이라는 규정된 경로로 스스로 재개했습니다.

사용자 게이트 4건

전부 승인 기록 완비

첫째, 헌법 2조에서 새 세션 규율의 대상을 Phase 워커 세션으로 확정했습니다. 둘째, Phase 4의 수용 판정 2건을 승인했습니다. 셋째, Phase 5에서 역할 제한을 푸는 명령은 사용자가 직접 실행해 검증했습니다. 넷째, Phase 6의 워커 기동은 헌법 9조의 예외로 이번 한 번만 승인했습니다. 네 건 모두 검증 기록이나 결정 대장에 [USER] 줄로 남아 있습니다.

마감 전 교차 검수 두 축

마감 판정에 앞서 서로 독립된 두 검수를 진행했습니다. 하나는 Claude 계열 리뷰어의 1차 검수이고, 다른 하나는 다른 회사 모델인 Codex의 교차 검수입니다.

두 검수 모두 기록이 가리키는 커밋, 훅 원본 대조 결과, 감시 로그와 테스트 재현 결과가 실물과 모두 일치한다고 판단했습니다. 다만 결함을 어떻게 분류할지에서는 의견이 갈렸습니다. 감독 세션이 의견이 갈린 항목을 모두 직접 재현해 최종 분류를 내렸습니다.

판정 예외 후보 ① — 문서 편제 네 갈래가 git 이력에 없음

사용자 판정 필요

문서 거처는 다섯 갈래지만, 그중 아키텍처·요구사항·보고서·디자인의 네 갈래는 빈 폴더입니다. 버전 관리 도구인 git은 빈 폴더를 저장하지 않으므로, 이 저장소를 새로 내려받으면 네 갈래가 사라집니다. 감독 세션이 직접 재현해 확인했습니다.

이는 「표준 레이아웃 물리 완성」이라는 기록 주장과 어긋나는 이식성 결손입니다. 자리 표시 파일을 넣어 작게 수리하거나, 검증 기록에 한계를 밝히는 정정 줄을 남길 수 있습니다.

판정 예외 후보 ② — 동시 쓰기 무손실 PASS의 증거가 정황 수준

사용자 판정 필요

Phase 5에는 두 세션이 상태 파일에 동시에 써도 서로의 기록을 지우지 않는다는 PASS가 있습니다. 그러나 실제 근거는 7분 간격으로 이어진 순차 기록과 직렬로 실행되는 재현 도구입니다. 감독 세션이 도구의 실행 구조를 다시 확인했습니다.

무손실이 깨진 반례가 나온 것은 아닙니다. 다만 증거의 강도가 주장에 미치지 못합니다. 검증 기록에 증거의 한계를 밝히는 정정 줄을 남기거나, 두 세션을 실제로 동시에 실행해 다시 측정할 수 있습니다.

하네스 강도 결함 — 두 검수가 합류한 실결함

다음 수리 대상 후보

위험 명령 가드에는 Moodie 원본보다 넓은 우회면이 있습니다. 재귀 삭제 명령에 긴 형태나 뒤쪽 플래그를 쓰는 경우, 플래그를 따옴표로 감싼 경우, git.exe나 대문자 Git을 쓴 경우에는 판정 없이 통과합니다. 이 가운데 3건은 감독 세션이 직접 재현했습니다.

테스트 가드는 일부 테스트만 실행해 통과해도 전체 통과의 증거로 받아들입니다. 훅 자체를 고칠 때는 훅 테스트를 동반 테스트로 인정하지 않습니다. 마감 게이트가 세션별로 스탬프를 판정하지 않는 문제는 Backlog 6번과 원인이 같습니다. 이 결함들은 이번 무인 완주 결과를 뒤집지는 않지만, 하네스를 믿고 무인 작업 범위를 넓히기 전에 고칠 가치가 있습니다.

Codex 심각 5건 중 3건의 하향 이유

감독 세션 판정

M01의 완료선은 하네스가 완전무결하다는 증명이 아닙니다. 이식한 하네스의 감독 아래에서 무인 작업 한 건이 완주하는지를 확인하는 것입니다.

가드 우회, 테스트 가드의 완화된 판정, 마감 게이트의 적용 범위는 실제 결함입니다. 그러나 두 검수 모두 무인 완주 자체는 실물로 확인했습니다. 따라서 감독 세션은 이 세 결함이 마일스톤 판정을 뒤집지 않는다고 분류했습니다. 링크 검사기의 정규식 사각, 계획 게이트의 느슨한 절 판독, 사용되지 않는 참조 등 나머지 보통·관찰급 지적은 검수 원문과 함께 Backlog 후보로 넘깁니다.

Codex는 설정에 등록된 훅에 누락이나 중복이 없다는 점도 확인했습니다. M01 문서는 모두 250줄 이내였고 작업 트리에는 미반영 변경이 없었습니다. 또한 결정 기록 ADR-001이 예고한 부채 두 건이 아직 장부에 등재되지 않았다고 지적했습니다. 셸을 거친 파일 쓰기를 허용한 문제와 Orca 경로가 심사를 거치지 않는 문제입니다. 두 항목은 이번 마감 절차의 이월 단계에서 처리합니다.

M01에서 하지 않은 일

아래 항목은 실패나 누락이 아닙니다. 처음부터 범위 밖이었거나 사용자 승인이 필요한 일입니다.

  • 원격 push: 수행하지 않았습니다. 마감 판정 뒤 사용자 승인 게이트를 거쳐 진행합니다.
  • Moodie 결정 장부의 이월 기록 한 줄: 마감 판정 뒤에 남깁니다.
  • Backlog 8건의 실행: 사용자의 결정을 기다리고 있습니다.
  • 이 보고서의 마감 판정: 보고서 작성까지가 이번 세션의 몫입니다. 최종 판정은 사용자 게이트로 남겨 두었습니다.

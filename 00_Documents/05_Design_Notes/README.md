# 설계 논의본 거처

하네스 설계의 **논의본**이 사는 자리입니다. 확정본이 아니라 과정 기록이라는 점에서 다른 갈래와 갈립니다.

여기 있는 문서는 쟁점 하나가 문서 하나를 갖고, 논의가 끝나면 그 문서 말미의 「결정」 절에 결론과 날짜를 적는 형식입니다.
확정된 내용은 여기 머무르지 않고 규칙·아키텍처·마일스톤 계획으로 승격됩니다 — 승격 뒤에도 원 논의는 경위 기록으로 이 자리에 남습니다.

색인은 `00_쟁점-목록.md`입니다.

거처가 이 자리로 정해진 근거는 M02 Phase 5의 처분 목록 승인([USER] 2026-08-10, 안건 ② 안 라-3)입니다.
아키텍처(`00_Architecture/`)나 디자인(`04_Design/`)에 섞지 않고 별 갈래를 세운 이유는, 이 문서들이 확정본이 아니라 논의본이라 두 갈래의 소유권 문면과 성격이 다르기 때문입니다.

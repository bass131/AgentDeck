## 목표

앱 안에서 메인 대화가 문답으로 전역 Taste와 프로젝트 헌장(목표와 프로젝트 Taste)을 채우고, 검수 노드가 그 Taste로 결과물을 판정해 검증 기록에 줄을 남긴다. 사용량 한도에 닿으면 루프가 안전한 지점에서 멈췄다가 한도가 풀리면 스스로 이어 간다.

## 범위

- **만들 것**
  - 문서 형식과 거처 — 전역 Taste는 앱 데이터 폴더, 프로젝트 헌장과 프로젝트 Taste는 그 저장소 안 문서로 커밋한다(3회차 1번). Taste 항목은 비전의 세 칸(원칙·레퍼런스·금지) 가운데 하나 이상을 가진다. 저장소 안 자리는 `.agentdeck/` 밖의 사람이 읽는 문서다(제안 — `docs/agentdeck/헌장.md`·`Taste.md`, 실행기 상태와 섞지 않는다).
  - 문답 — 메인 대화 안에서 여러 턴으로 묻고 답을 스펙으로 정리한다. M10의 질문 카드와 승인 카드를 쓴다. 전역 Taste는 처음 한 번과 사용자가 고칠 때, 프로젝트 헌장은 프로젝트를 열었는데 헌장이 없을 때 연다. 문답이 끝나면 승인 카드로 확정한다.
  - 화면 — 작업 모드에서 전역 Taste와 프로젝트 헌장을 보고, 고치고 싶으면 메인 대화로 다시 문답을 연다(제안 — 직접 편집칸은 두지 않는다. 판정할 수 있는 꼴을 문답이 지키게 하려는 것이다).
  - Taste 판정 — 「프로그램 개발」 템플릿의 검수 노드가 프로젝트 Taste와 전역 Taste의 항목을 체크리스트로 읽고, 판정마다 항목을 근거로 검증 기록에 `PASS`·`FAIL` 줄을 남긴다. 두 층이 겹쳐 충돌하면 프로젝트 Taste를 따르고 충돌을 결과 보고의 「영역 재설계 안건」에 올린다(비전).
  - 노드 세션의 설정 원천 — 메인 대화와 작업 노드는 사용자 전역 설정(`settingSources`의 user)을 싣지 않고, 앱의 Taste와 헌장을 대신 싣는다(제안, M10 Backlog 11 — 남에게 건넬 수 있는 조건과 노드 세션 격리). 채팅 모드는 그대로 둔다.
  - 사용량 한도 — SDK의 한도 사건(`SDKRateLimitEvent`, 공개 타입)을 읽는다.
    - 경고 단계(`allowed_warning`)면 지금 노드는 끝까지 하고 다음 노드를 시작하지 않고 멈춘다. 거부(`rejected`)면 그 노드를 멈추고, 이어 갈 때 그 노드를 처음부터 다시 한다(제안).
    - 멈춘 지점과 풀리는 시각(`resetsAt`)을 생존 문서와 실행 상태에 남기고, 그 시각이 지나면 앱이 스스로 이어 간다. 앱을 껐다 켜도 이어 간다.
    - 초과 사용이 켜져 있어도 멈춘다(3회차 2번 「멈춘다」).
    - 알림은 「나중에 봐도 되는 사건」이다 — 앱 안 표시만 하고 Windows 알림은 띄우지 않는다(비전 「알림」).
    - 남은 사용량 표시는 실험 API(`usage_EXPERIMENTAL…`)에 기대지 않는다. 한도 사건의 `utilization`만 쓴다(제안 — 공식 타입이 「기대지 말라」고 적었다).
  - 문장 규칙 문서(M05 Backlog 75) — 전역 Taste의 「문서 말투」 항목으로 흡수한다.
- **건드릴 곳**
  - 판정 장치: `98_Management/01_GateState/gate-config.json`(`planPath`·`workPinPath`)만.
  - `02_Project/00_Source/`(main의 Taste·헌장 저장, 문답, 검수 노드, 한도 처리, renderer의 작업 모드 화면), `02_Project/01_TestCode/`, 「프로그램 개발」 템플릿, `01_Milestones/M12_CharterTaste/`, `01_Milestones/00_Roadmap.md`.
- **하지 않을 것**
  - Second Brain 자동 동기화(비전 — 사용자의 별도 스킬 몫). 앱 Taste를 Second Brain에 쓰지 않는다.
  - 레퍼런스 칸의 스크린샷 대조 자동화(이미지 비교). 레퍼런스는 링크와 캡처를 저장하고 검수 노드가 읽을 수 있게만 한다(제안).
  - 실제 사용량 한도까지 일부러 쓰기(비용). 설치본, GitHub 로그인(M13).
- **완료조건**
  - 연습 저장소 `bass131/AgentDeck_Test`에서 작업 모드의 메인 대화가 전역 Taste와 프로젝트 헌장 문답을 끝내고 승인 카드로 확정한다. 프로젝트 헌장·Taste 문서가 그 저장소에 커밋되고 전역 Taste가 앱 데이터 폴더에 있다(사람 몫 — 문답의 답, 스펙 승인, 연습 저장소 `main`으로 가는 마일스톤 PR의 앱 병합 버튼 — 은 M10처럼 메인이 e2e로 대행한다. 답은 Second Brain 개발 성향에서 가져온다. M11 결정 대장 1회차).
  - 이어서 새 마일스톤 M03을 완주하고, 그 검증 기록에 Taste 항목을 근거로 든 검수 줄이 한 줄 이상 있다.
  - 사용량 한도 — 시험이 경고·거부 사건으로 멈춤, 풀리는 시각 뒤 자동 이어 가기, 재기동 뒤 이어 가기, 초과 사용 중에도 멈춤을 묶는다. 실주행에서는 실행기 앞단에 한도 사건을 주입해 한 번 멈췄다가 이어 가는 것을 관찰한다. 실제 한도에 닿으면 그것도 기록한다.
  - 마일스톤 결과 보고에 장면 캡처(문답, 승인, 헌장 보기, 한도 멈춤 표시)를 싣는다.
  - 마일스톤 회귀 검증 `PASS` 줄이 아래 검증 기록에 있다.

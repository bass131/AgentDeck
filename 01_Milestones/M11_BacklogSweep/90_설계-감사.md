## 주제별 핵심

1. **판독기 사본의 어긋남(가장 큼)**
   - 셸 판독이 가드·`mergeDeny`·`loopLock`에 두 벌 반 있다. 가드는 막고 앱은 통과시키는 꼴 10개를 실측했다(Backlog 17).
   - GitHub PR 판독은 앱 PR 카드·현황판·루프 실행기에 세 갈래로 있고, 이미 네 곳이 어긋났다. 현황판 시험은 자동 게이트 밖이다.
   - 같음 시험이 표의 글자만 비교해서 판독 함수를 지키지 못한다.
2. **거대 분기 함수**: 스트림 매핑, 이벤트 정규화, 셸 걷기가 if 사슬이다. 같은 구역의 가드 규칙 표(`{id, why, match}`)와 노드 등록부(`controlNodes.ts`)가 따를 본보기다.
3. **팩토리 클로저**
   - `createLoopDriver`는 가변 필드가 22개이고, 상태 계산·래치 풀기·구동 펌프·카드 등록부가 한 곳에 있다.
   - 노드 종류 술어가 네 곳에, 상태 파일 쓰기 순서가 두 곳에 있다.
4. **renderer 결합**
   - 29모듈 순환이 있다. import 다섯 줄과 `MarkdownView`·`PaneSplitter`를 `02_Common`으로 내리면 0이 된다.
   - 상태 관리 방식이 여섯 종이다. 루프 상태 구독이 네 벌이고, 메인 대화 전용 렌더러·입력창이 따로 있다(goal 4가 맡음).
   - 도달할 수 없는 패널 코드가 1,033줄 있다(goal 6의 M10-3).

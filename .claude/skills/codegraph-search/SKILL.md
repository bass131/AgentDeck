> **왜 이 스킬인가**: 에이전트는 구조를 grep·Read 루프로 한 파일씩 재발견한다 — CodeGraph는 그 루프를 그래프 질의 1~5콜로 대체한다. 서브에이전트(MCP 도구 없음)도 아래 CLI를 Bash로 그대로 쓸 수 있다. 실측 근거(2026-07-28 파일럿): callers 정밀도·재현율 100%(주석·유사심볼 허수 전부 제거 — 주석 밀도 높은 우리 코드베이스에서 grep 대비 이점 큼).

### 0. 전제

`.codegraph/codegraph.db` 없으면 이 스킬 전체를 건너뛰고 평소처럼 Grep/Read를 쓴다 (인덱싱은 사용자 결정 — codegraph-init 제안만).

### 1. 도구 선택표 — 질문 유형에서 바로 고른다

공통 프리픽스: `CODEGRAPH_TELEMETRY=0 DO_NOT_TRACK=1 npx -y @colbymchenry/codegraph@latest`

| 질문 | 명령 | 신뢰도·주의 (실측) |
|---|---|---|
| 이 심볼 어디 있어? | `query <이름>` | 퍼지 매칭 — 후보 나열용 |
| 이 심볼 정의+관계 전부 | `node <심볼>` | **심화 1순위** — verbatim 소스 + 호출자/피호출자 트레일. 동명 오버로드는 전부 반환 |
| 누가 이걸 호출? | `callers <심볼>` | ✅ 정밀 (실측 100/100) |
| 이게 뭘 호출? | `callees <심볼>` | ✅ 정밀 |
| 바꾸면 어디까지 영향? | `impact <심볼>` | ⚠️ **상한 추정** — 전이 폐쇄가 꼬리에서 과대 포함(실측: 무관 config까지 등장). 정밀 목록이 아니라 "이 밖은 안전" 경계로만 사용 |
| 이 파일들 바꾸면 어떤 테스트? | `affected <파일...>` | 회귀 게이트 보조 — 국소 테스트 선별에 사용 |
| 흐름·영역 탐색 (진입점 모를 때) | `explore "<심볼명 나열>"` | ⚠️ 질의는 자연어 문장이 아니라 **심볼명 모음**으로 (실측: 자연어는 키워드 오염 — "prompt"에 PromptModal이 딸려옴). 출력 ~28KB로 큼 — 진입점 잡은 뒤엔 node/callers로 전환 |
| 인덱스된 파일 구조 | `files` | 트리 요약 |

### 2. 해석 규율

- 결과를 **정본으로 단정하지 말 것** — 인덱스는 마지막 sync 시점 스냅샷이다. 방금 편집한 파일이 관련되면 codegraph-update 먼저.
- `explore` 출력의 소스 블록은 "디스크에서 방금 재독한 verbatim"이라고 도구가 보증한다 — 같은 파일을 다시 Read하지 않는다(토큰 절약이 이 도구의 존재 이유).
- 에러 1~2회에 도구를 버리지 말 것: ① `unlock`+`sync` ② 재시도 ③ 그래도 실패면 Grep/Read 폴백 + "인덱스 문제"를 사용자에게 보고.

### 3. 금지

- `install`/`uninstall` 서브커맨드 — 하네스를 외부에서 수정한다. 어떤 상황에도 실행 금지(permissions deny 이중 차단).
- 데몬 기동(`daemon`) — 상주 프로세스 0 정책.

# V1 아카이브

여기에는 하네스 v1 시절의 실행 상태 파일이 들어 있습니다.
M01 Bootstrap Phase 1에서 원래 자리(`.claude/state/`와 `.codex/state/`)를 비우면서 옮겨 왔습니다.

옮기기만 하고 지우지 않은 이유는 감사 이력이기 때문입니다.
`guard-blocks.log`는 위험 명령 가드가 실제로 무엇을 몇 번 막았는지를 담고 있고, `circuit-breaker.log`는 반복 실패로 차단이 걸린 이력을 담고 있습니다.
새 하네스가 같은 상황에서 같은 판정을 내는지 나중에 대조하려면 이 기록이 있어야 합니다.

- `claude-state/` — `.claude/state/`에 있던 로그 세 개입니다.
- `codex-state/` — `.codex/state/`에 있던 파일 전부입니다.

주의할 점이 하나 있습니다.
`claude-state/`의 로그 세 개는 `.gitignore`에서 명시적으로 제외돼 커밋되지 않고 이 머신에만 남습니다.
합쳐서 60만 바이트대라 저장소 이력에 박기 전에 사용자 판단이 필요하다고 보고 기본을 제외로 뒀습니다.
다른 머신에서도 이 이력을 봐야 한다면 `.gitignore`의 해당 두 줄을 지우면 됩니다.
`codex-state/`의 두 파일은 작아서 그대로 커밋합니다.

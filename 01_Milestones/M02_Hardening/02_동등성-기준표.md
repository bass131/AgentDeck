이 문서는 M02 완료선 둘째 조항(「위험 명령 가드가 Moodie 원본 표면과 동등 이상임을 테스트로 증명한다」)의 사람용 정본입니다.
기계 배선은 `.claude/hooks/cmd-guard-equivalence.test.mjs`이고, 두 표면의 항목 id와 기대 판정은 같아야 합니다.
대조 대상은 원본 `C:\Dev\Moodie_Agent_Workflow\.claude\hooks\32_cmd-guard.cjs`와 현행 `.claude/hooks/dangerous-cmd-guard.mjs`입니다.

## 판정 축과 읽는 법

판정은 세 값으로 접습니다.

- **deny** — 차단입니다. 현행 가드는 exit 2로, 원본 가드는 `permissionDecision: "deny"` JSON으로 냅니다.
- **ask** — 승인 질의입니다. 현행 가드가 비가역 축(push·publish·release)에 쓰며, 차단과 동등으로 읽습니다 (M01 결정 대장 [USER] 2026-08-09).
- **allow** — 통과입니다. exit 0에 출력이 없는 상태입니다.

기대 판정의 원칙은 「원본 동등 이상」입니다.
원본이 잡던 표면은 반드시 잡고, 원본보다 넓게 잡는 것은 그대로 둡니다.
반대로 하류에서 실행되지 않는 언급·인용문을 잡는 것은 오탐이므로 기대 판정을 allow로 둡니다 — 오탐도 동등성 결함입니다.

**플래그** 열의 ✔은 현행 구현이 기대 판정과 어긋남이 확인된 표면입니다.
그 항목은 기대-실패 플래그로 등재되어 있어 「실측이 기대와 다르면 통과」로 집계됩니다 — 하드 게이트를 유지하면서 Red를 기록하는 장치입니다 (플래그 의미론은 `.claude/hooks/_lib/runner.mjs`가 소유).
플래그 잔여가 0이 되는 시점이 동등성 증명의 완료이고, 수리는 Phase 2의 몫입니다.

## heredoc pipeline

heredoc이 붙은 명령은 pipeline 전체를 한 항목으로 등재합니다.
기대 판정의 기준은 본문이 어디로 흘러가는가입니다 — **하류 실행 소비자**(`bash`·`sh` 류)나 **파일 sink**(실행 스크립트 생성)가 있으면 deny이고, 커밋 메시지처럼 실행되지 않는 소비자뿐이면 allow입니다.

## 인용 벗기기와 세그먼트 분할

두 구현의 전처리가 다르고, 회귀와 오탐이 모두 이 차이에서 나옵니다.

- **원본** — 명령 문자열을 `&&`·`||`·`;`·`|`·`&`·개행으로 나누고, 각 세그먼트를 공백으로 토큰화한 뒤 **토큰에서 따옴표 문자를 제거**합니다. 그래서 `"rm" -rf dist`와 `git reset "--hard"`를 잡습니다. 대신 인용 안의 본문도 명령으로 읽어 `git commit -m "a && rm -rf /"`를 오탐합니다.
- **현행** — 문자 단위로 훑으며 따옴표 안의 내용을 **세그먼트에서 통째로 버립니다**(Backlog 3). 그래서 커밋 메시지 오탐이 없는 대신, 인용으로 감싼 명령·플래그를 보지 못합니다(RM-08·GR-02).
- **머리 토큰 판정** — 두 구현 모두 git 계열 규칙은 세그먼트의 첫 토큰이 `git`일 때만 적용합니다. 현행은 여기에 전역 옵션 건너뛰기(`-C <경로>`·`--git-dir=…`)를 더해 `git -C repo reset --hard`를 잡습니다.
- **비git 규칙** — 원본은 `rm`·`del`·`npm`을 토큰 스캔으로 보고, 현행은 세그먼트 정규식으로 봅니다. 현행의 정규식은 플래그가 `rm` 바로 뒤에 붙은 형태만 잡아 RM-03~05 회귀가 생겼습니다.

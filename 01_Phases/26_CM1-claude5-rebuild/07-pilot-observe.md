# Phase 07: 파일럿 + 관찰 확정

> **상태**: pending · **마일스톤**: CM1 · **등급**: 복잡 · **담당**: 새 하네스의 새 세션 (관찰 기록 = 메인, 판정 = 영호)

## 🎯 목표

"지운 것들이 실제로 불필요했는가"가 감이 아니라 데이터로 판정되고, 복원할 것은 복원된 상태로 트랙이 종결된다.

## ⏪ 사전 조건

- [ ] Phase 06 완료 (새 하네스 라이브)

## 📝 작업 내용

- [ ] **파일럿 트랙 선정** — 기준: 위험 깃발 3종 이상 노출되는 실전 개발 트랙(UI 전용 트랙 불가 — 깃발 분포 편향 방지). 후보: RS2 등, 영호 결정.
- [ ] **[파일럿 시작 전] "해야 할 것" 사후 체크리스트 실물 확정** — Phase 03·04 결정에서 추출(어떤 규범을·언제[턴/Phase/종결] 대조하는지). 사후 재구성 금지 — 복원 트리거와 같은 사전 선언 규율 (plan-auditor 🟡3).
- [ ] **관찰 장비 3종 가동**:
  1. 무음 원장(폐지 advisory의 로그 전용 모드)의 **would-have-fired 카운터** — "울렸을 알림"의 실측
  2. **"해야 할 것" 사후 체크리스트 대조** — reviewer 호출·게이트 실행 등 문서 규범의 누락은 침묵 실패라 보이는 실수만 세면 놓친다
  3. 실수·재작업 기록 (`_decisions.md`에 이어서)
- [ ] **복원 트리거 판정 (사전 선언 — 파일럿 시작 전 변경 금지)**:
  - 비가역 인접 실수 1회 → 해당 게이트 **즉시 복원**
  - 특정 advisory 부재에 기인한 재작업 2회 → 해당 훅 복원
  - 문서 규범 누락 반복 → 해당 문서 복원
- [ ] **트랙 종결**: 관찰 반영(복원/확정) → CHANGELOG 한 줄 + 회고 → Second Brain 축적 제안 1건(이사 방법론 일반화) → CM1-DONE.md.

## 📚 학습 포인트

- 카운터팩추얼 관측 — 지운 것의 효과는 "없어서 생긴 일"이라 관측 장비를 미리 심어야 보인다.
- 사전 선언(pre-registration) — 판정 기준을 결과를 보기 전에 고정해야 확증 편향을 막는다.

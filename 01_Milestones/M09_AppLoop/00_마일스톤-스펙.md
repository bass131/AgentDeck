## 목표

앱이 선언형 템플릿 「프로그램 개발」을 읽어 마일스톤 하나를 작업 그래프로 돌린다. 순서와 게이트는 프로그램이 쥐므로 에이전트는 단계를 건너뛰지 못한다. 그 루프로 버려도 되는 연습 저장소의 작은 마일스톤 하나를 앱만으로 끝까지 완주한다.

## 범위

- **만들 것**
  - 템플릿과 실행기 — 노드·게이트·순서를 데이터 파일로 적은 「프로그램 개발」 템플릿과, 그 파일을 읽어 실행하는 앱 메인 프로세스의 작은 실행기. 템플릿 파일 꼴은 JSON과 스키마 검사다(제안).
  - 작업 노드 — 노드마다 담당 Agent SDK 세션에 그 노드의 지시와 생존 문서만 준다. 브레인스토밍과 스펙 쓰기는 메인 세션이 한다.
  - 게이트 노드 셋
    - 규칙 게이트: 테스트·린트·CI 결과, 검증 기록의 마지막 줄.
    - 모델 게이트: 강 등급 goal의 독립 검수. 구현 문맥이 없는 세션이 판정한다.
    - 사람 게이트: 스펙 승인 카드 한 번, 마일스톤 병합(M07 병합 버튼).
  - 결정론적 동작은 실행기 코드가 한다 — 브랜치 가르기, 커밋 뒤 push, PR 생성, CI 대기, 머리 SHA 대조, 마일스톤 브랜치로의 로컬 `git merge --no-ff`, 마일스톤 PR 생성(제안).
  - 생존 문서는 작업 저장소 안 전용 폴더에 둔다(제안: `.agentdeck/`): 마일스톤 스펙, goal 문서, 결정 대장, 검증 기록. 실행기는 앱을 다시 켜도 이 문서에서 멈춘 노드를 다시 읽어 이어 간다.
  - 사람을 부르는 예외(범위·완료조건 변경, 같은 곳 FAIL 세 번)는 앱 안에 최소 표시 한 줄로 보인다. 알림과 앱 안 현황판은 다음 마일스톤이다.
  - 로드맵 재작성 — M09를 둘로 나눈다. M10은 v1 줄기의 나머지(헌장·Taste 문답, 앱 안 현황판, 알림, 사용량 한도)가 되고, 설치본과 업데이트는 M11이 된다.
- **건드릴 곳**
  - 판정 장치(헌법 3·11조, 이름으로): `98_Management/01_GateState/gate-config.json`(`planPath`·`workPinPath`)과, 위험 명령 가드 `.claude/hooks/dangerous-cmd-guard.mjs`와 그 시험(`dangerous-cmd-guard.test.mjs`·`cmd-guard-equivalence.test.mjs`)이다. 가드는 `env -S`처럼 문자열을 명령으로 다시 읽는 꼴의 병합 차단 구멍을 실측해 막는 데만 고친다(G2 뒤 사용자 결정 4A).
  - `02_Project/00_Source/`(main의 새 실행기 모듈, 세션·git·PR 연결, renderer의 승인 카드와 예외 표시), `02_Project/01_TestCode/`, `01_Milestones/M09_AppLoop/`, `01_Milestones/00_Roadmap.md`.
- **하지 않을 것**
  - 헌장·Taste 문답, 앱 안 현황판, 알림, 사용량 한도 멈춤과 이어 가기(1회차 1A — M10).
  - 그래프 편집 화면, 게임 템플릿, 예약 운영 루프, 설치본과 업데이트.
  - 비공개 전환 대비 — M08 Backlog 2와 앱 쪽 `master` 보호(1회차 4B).
  - 이 저장소의 CLI 하네스(헌법, 훅, 설정) 변경 — 위 「건드릴 곳」의 위험 명령 가드 구멍 막기만 예외다. 연습 저장소에는 CLI 하네스를 깔지 않는다.
  - 연습 저장소 만들기와 그 `master` 병합(사람 몫).
- **완료조건**
  - 템플릿이 데이터 파일 하나로 있다. 시험이 템플릿의 노드를 빼거나 순서를 바꾸면 실행 순서가 그대로 바뀌는 것을 본다.
  - 게이트를 건너뛰지 못한다. 시험이 규칙·모델·사람 게이트 각각이 통과하지 않으면 다음 노드로 가지 않는 것을 본다.
  - 연습 저장소에서 앱만으로 마일스톤 하나를 완주했다.
    - 경로: 앱 안 브레인스토밍 → 스펙 승인 카드 → goal 둘 이상 → goal마다 CI 통과(강 등급이면 검수) → 마일스톤 브랜치 로컬 병합 → 회귀 → 마일스톤 PR → 사용자가 앱 병합 버튼으로 병합.
    - 사람의 개입은 브레인스토밍 답, 승인 한 번, 병합 한 번이다. 예외 호출은 횟수와 이유를 남긴다.
  - 재개: 그 완주 도중 앱을 한 번 껐다 켜도, 연습 저장소의 생존 문서에서 멈춘 노드부터 이어 갔다(실측 한 번).
  - 마일스톤 회귀 검증 `PASS` 줄이 아래 검증 기록에 있다.

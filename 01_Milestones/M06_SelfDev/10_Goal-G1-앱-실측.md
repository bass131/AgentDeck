실행 단계 일괄 승인 대상 (로드맵 예외로 합의 문답 없이 진행한다)

- `npm run dev`·`npm run start`로 앱 실행, Playwright Electron 하네스로 창 조작과 스크린샷(창은 2번 모니터), 앱 안 대화 세션(사용자 로그인 자격 — 파일은 읽지 않는다)
- 실험용 형제 작업 트리 `git worktree add`(이 저장소 밖 경로, 실험 뒤 `git worktree remove`)
- 하드 게이트 다섯 종, 하위 에이전트 기동, 커밋, 작업 브랜치 push, `gh pr create`

권한 실험의 안전 규칙

- 앱 세션의 작업 폴더는 실험용 형제 작업 트리다. 이 저장소 작업 트리를 앱 세션에 열지 않는다.
- 가드가 묻는 명령은 허용돼도 아무 일이 없는 것만 쓴다 — 예: `git push --dry-run origin HEAD:master`(보내지 않고, 서버 보호도 거부한다). `gh pr merge`·브랜치 삭제·보호 설정 변경은 쓰지 않는다.

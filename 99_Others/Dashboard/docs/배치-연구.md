# 현황판 배치 연구 — 다른 진행·상태 화면은 무엇을 어디에 두는가

- 작성: 2026-11-14 · 목적: 「지금 무슨 일을 하고 있는지」가 한눈에 읽히는 배치를 정한다.
- 방법: 공개 문서와 제품 소개 글만 읽었다. 코드와 에셋은 가져오지 않았다. 출처는 맨 아래에 있다.

## 사례별 비교

| 사례 | 맨 위에 두는 것 | 진행 상태 표현 | 사람 손이 필요한 일 | 자세한 내용 |
|---|---|---|---|---|
| GitHub Actions 실행 화면 | 실행 이름, 전체 결과 한 개(성공·실패·진행 중) | 작업마다 왼쪽 끝에 상태 표시, 의존을 선으로 잇는 그래프 | 실패한 작업이 빨강으로 바로 보인다 | 작업을 눌러야 로그가 열린다 |
| GitHub PR 병합 상자 | 「병합할 수 있는가」 한 줄 | 검사 수를 통과·실패·진행 중으로 묶어 한 줄로 | 승인 필요, 충돌 같은 막는 이유를 버튼 바로 위에 | 검사 이름 목록은 펼쳐야 보인다 |
| Vercel 배포 목록 | 프로젝트 이름 → 상태 → 최근 배포 → 지표 순서 | 대기·빌드 중·오류·준비됨 네 낱말과 색 점, 탭 아이콘까지 같은 상태 | 오류만 색이 강하다 | 줄을 눌러야 빌드 로그 |
| Linear 프로젝트 | 프로젝트 설명 바로 밑에 마일스톤 목록 | 마일스톤마다 진행률, 상태는 몇 개의 이름으로만 | 막힌 이슈는 표시로 따로 | 이슈 목록은 마일스톤을 눌러서 |
| Jira 보드 | 할 일·진행 중·완료 세 칸 | 칸의 위치 자체가 상태 | 깃발 표시(막힘)를 카드에 | 카드를 열어야 본문 |
| 상태 페이지(Statuspage 류) | 전체 상태 한 문장(「모두 정상」·「일부 장애」) | 구성 요소 목록, 사람이 쓰는 이름으로 | 진행 중인 사건을 목록보다 위에 | 지난 사건 이력은 아래 |
| Grafana 류 관측 화면 | 증상 지표(요청 수·오류·지연)를 위·왼쪽에 | 같은 줄에 같은 서비스, 흐름 순서로 줄 배치 | 경보는 증상 기준으로 | 원인 지표는 아래 줄, 접는 줄 |
| 에이전트 진행 UI 글 | 지금 하는 일 한 줄(「12개 중 7번째 초안 작성」) | 빙글이 대신 구체적인 진척 | 위험한 순간에만 승인을 묻고, 승인 상자를 주 버튼처럼 | 실제로 실행될 내용을 승인 상자에 |
| 대시보드 설계 원칙 글 | 핵심 질문 하나의 답(5~10초 안에 읽힘) | 요약 → 원인 → 원문의 세 층 | 결정에 쓰이는 정도만큼 크게·위에 | 점진적 공개, 필요할 때 펼침 |

## 우리가 가져올 원칙

1. **맨 위는 세 질문의 답 세 줄이다.** 지금 무슨 일을 하나, 내 손이 필요한가, 전체 중 어디쯤인가. 상태 페이지의 「전체 상태 한 문장」과 PR 병합 상자의 「병합할 수 있는가」 한 줄을 따른다.
2. **이름은 사람이 쓰는 짧은 이름이다.** 단계 제목 원문은 작업 메모라서 길다. Vercel·상태 페이지처럼 짧은 이름만 보이고 원문은 펼쳐서 본다. 짧은 이름은 규칙으로 뽑고 지어내지 않는다.
3. **진행은 낱말 몇 개와 위치로 말한다.** 완료·진행 중·남음 세 가지로 충분하다(Jira의 세 칸, Linear의 마일스톤). 마일스톤 안 goal은 한 줄 칩 목록으로 놓아, 위치가 곧 진척이 되게 한다.
4. **사람 손이 필요한 일은 따로, 맨 위에, 노랑으로.** 없으면 「없음」이라고 쓴다. 비어 있음도 답이다. 에이전트 UI 글처럼 위험한 순간(병합 승인, 멈춤, 질문)에만 올린다.
5. **숫자는 한 곳에만 둔다.** 검증 기록 수는 「이 goal의 단계」 안 한 줄에만 둔다. 같은 수를 여러 곳에 두면 무엇이 기준인지 헷갈린다.
6. **근거를 숨기지 않는다.** 「지금 하는 일」 문장 밑에 어느 원문에서 왔는지 작게 쓴다. 원문으로 문장을 만들 수 없으면 추측하지 않고 「확인할 수 없음」과 출처를 쓴다.
7. **원인과 원문은 아래로, 접어서.** 요약 → 이 goal의 단계 → 최근 활동 → 원문의 순서다. 위로 갈수록 결정에 쓰이고, 아래로 갈수록 확인용이다.
8. **뜻이 안 통하는 배지는 문장으로 바꾼다.** 「사람용 문장 없음」·「방금 바뀜」 같은 내부 사정 배지는 없앤다. 바뀐 곳은 왼쪽 파랑 선만 남긴다.

실행 워커의 상비 규율이다. 스펙의 [완료 기준]·[금지·제약]과 함께 적용된다.

- 계획·스펙에 명시되지 않은 변경은 현장에서 실행하지 않는다. 발견은 최종 보고에 관찰로만 적는다 —
  그대로 두면 완료 기준이 깨지는 경우에만 ask로 승인을 받아 수정한다 (Backlog 규칙, M01 결정 대장 [USER] 2026-08-10).
- 파일 생성·수정은 Edit·Write 도구로만 한다. Bash 경유 파일 쓰기는 헌법 8조 위반이다.
- git push·publish는 하지 않는다. commit은 스펙이 명시적으로 허용할 때만 한다.
- 자기보고보다 실물을 남긴다 — 통과 주장은 실행 로그·경로·수치와 함께 적는다.

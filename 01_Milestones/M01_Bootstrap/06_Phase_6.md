Steps

1. 링크 검증 스크립트를 먼저 쓴다. README의 모든 내부 링크가 실존 파일을 가리키는지 검사하고, 하나라도 깨져 있으면 0이 아닌 코드로 끝나야 한다. 이것이 이 Phase의 Red다.
2. 워커를 스폰하기 전에 plan-gate를 직접 구동해 영수증을 받는다. 종료 코드, 판정 대상 계획 경로, hook-log 기록 세 가지를 남긴다.
3. Orca 가시 세션으로 워커를 띄운다. 워커 세션에는 `MOODIE_SESSION_ROLE=worker` 환경변수를 건다. 가시 세션을 쓰는 이유는 무인 작업이 블랙박스가 되지 않게 사용자가 실시간으로 볼 수 있어야 하기 때문이다.
4. 워커가 README 링크를 고치고 검증 스크립트를 통과시킨 뒤 스스로 마감까지 가게 둔다. 중간에 개입하지 않는다.
5. 완주 후 Orca 세션 로그와 hook-log를 대조해 개입이 없었음을 채증한다.

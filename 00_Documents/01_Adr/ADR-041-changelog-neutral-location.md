# ADR-041: CHANGELOG를 `00_Documents/`로 이동 — 엔진 중립 위치 + `.claude/`는 봉인된 포인터

**결정(BZ P06 창 2, 2026-07-28 — 영호 GO 2026-07-27)**: `.claude/CHANGELOG.md`를 `00_Documents/CHANGELOG.md`로 이동(`git mv`)하고, `.claude/CHANGELOG.md`는 **한 줄 포인터**로 신규 생성해 옛 경로 참조가 죽지 않게 한다. **이동 후 포인터는 다른 `.claude/**` 파일처럼 CORE-11 봉인 대상**이다 — `shell-policy.mjs`의 `.claude/changelog.md` allowed 예외를 **제거**하고 골든 픽스처를 반전한다(Codex 교차 리뷰 축 2 — 원안 "예외 존치"는 방향이 반대였다: 예외의 근거는 "수시 갱신되는 기록"이었는데, 이동 후엔 그 성질이 신 위치로 떠나고 포인터만 남는다). 신 `00_Documents/CHANGELOG.md`는 일반 문서 판정이라 별도 허용 예외가 필요 없다.

**이유**: `BACKLOG.md` 16 — 한 파일이 두 정체성을 갖고 있다. **위치**는 `.claude/` = Claude 어댑터 층(ADR-034 3층)인데, 파일이 스스로 선언한 **역할**은 "헌법·ADR·하네스·공유계약 변경 이력" = 저장소 전체 이력이다. 실사고: Codex가 자기 변경을 커밋하기 전 *"이 이력을 `.claude/CHANGELOG.md`에 기록해도 되는가"*로 멈춰 섰다(2026-07-26). 그때는 운영(잡무 기준 v1 — "CHANGELOG 문구 = 메인 직접")으로 비껴갔지만 구조는 그대로다 — 다음에 Codex가 단독 변경을 하면 같은 질문이 다시 온다.

**대안과 트레이드오프**:
- (a) *현행 유지 + 운영 규칙* — 이번 건 처리 방식. 비용 0이나 구조 미해결(엔진이 늘 때마다 같은 질문).
- (b) *엔진별 CHANGELOG 분리*(`.claude/`·`.codex/` 각자) — 소유권은 깔끔하나 "저장소 전체 이력"이라는 역할 자체가 사라진다. 헌법·CORE·공유계약처럼 엔진을 넘는 변경의 이력이 갈 곳이 없다.
- (c) **채택: 중립 위치 이동** — 엔진 중립 위치를 얻는 대신 **역참조 스윕이 본체**인 비용을 낸다(BACKLOG.md 이관 선례 실측 — "이관 자체보다 역참조 스윕이 본체"). 백로그 5 전례: "3곳" 추정이 크게 벗어났다 — 추정 금지, 전수 실측(BZ P05에서 수행, 아래 §2).

## 1. 이동 설계

- `git mv .claude/CHANGELOG.md 00_Documents/CHANGELOG.md` + `.claude/CHANGELOG.md` 한 줄 포인터 신규 생성 + 참조 치환을 **원자 커밋 하나**로(중간 상태가 이력에 남지 않게 — P06 함정 절).
- 포인터 내용: `# → 이동됨: 00_Documents/CHANGELOG.md (ADR-041, 2026-07-28) — 이 파일은 하위 호환 포인터이며 편집하지 않는다.`
- **봉인 의미 전환**: 이동 전 `.claude/CHANGELOG.md` = 봉인 예외(수시 갱신 기록) → 이동 후 = 봉인 대상(고정 포인터). `shell-policy.mjs` 예외 줄 제거 + `shell-policy.test.mjs`의 편집 허용 고정 픽스처 반전 + 주석 정정. 훅 수정 = 골든 픽스처 동반(BZ P01 규율).
- Codex 어댑터의 동일 의미 예외(`agentdeck-hook.mjs` `:381` `isHarnessPath()`·`:419` 셸 허용 목록 — Codex 자기 실측)는 CORE-12로 Claude가 수정 불가 → **BZ P07 인계 명세**로 Codex 세션에 이월(P06과 대칭 방향의 독립 구현 + `hooks.json` digest 8개 갱신 동반).

## 3. 검증

- 마크다운 링크 체커 무회귀 + 「치환」 판정 건수 = 반영 건수 이름 단위 대조 (P06 완료 조건).
- 이동 후 `.claude/CHANGELOG.md` 쓰기 시도가 차단되는 라이브 프로브 1회(창 폐쇄 후 — 봉인 전환의 실측).

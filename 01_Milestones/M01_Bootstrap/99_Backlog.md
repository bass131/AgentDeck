## 대기 항목

1. **gh·npm 규칙의 정규식 판정 잔존** (Phase 3 관찰) — dangerous-cmd-guard에서 git 계열은 머리 토큰 판정으로 바꿨지만, gh pr·gh release·npm publish 규칙은 아직 정규식이라 판정 방식이 갈립니다. 같은 토큰 방식으로 맞출지 검토가 필요합니다.
2. **partition 픽스처 3종의 커버리지 축소** (Phase 4 관찰) — preview-only·no-tag·no-record 픽스처가 원래 겨눴던 검사(Phase 구획 없음·태그 부재·검증 기록 절 부재)에 닿기 전에, 그 앞 단계인 사람용 개요 검사에서 먼저 반려됩니다. 세 픽스처의 Preview에 「사람용 개요」 절을 넣어야 원래 검사까지 도달합니다.
3. **scanSegments의 인용부 통째 드롭** (Phase 3 관찰) — 현행 가드는 인용부 안 문자를 세그먼트에서 버립니다. 인용문 오탐을 막아 주는 대신, 인용 안에 숨긴 위험 명령도 보지 못하는 트레이드오프입니다.
4. **헌법 2조 문안 명확화** (2026-08-10 해석 확정의 후속) — 루트 CLAUDE.md와 AGENTS.md의 2조에 「새 세션 규율의 대상은 Phase 워커 세션」 문장을 넣는 일입니다. 문안 초안은 있고, 사용자 승인과 워커 편(메인 세션은 루트 파일 편집 불가)이 필요합니다.
5. **모델 라우팅 정책에 Backlog 규칙 반영** — `00_Documents/02_Rules/02_모델-라우팅-정책.md`의 스펙 문법 절에 「계획 밖 변경 금지 — Backlog 보고」 조항을 추가하는 일입니다. 00_Documents 편집이라 워커 편이 필요합니다.
6. **코디네이터 pin 갱신이 워커의 stop-gate 장전을 간섭** (Phase 5 관찰) — 코디네이터가 자기 마감으로 pin 스탬프를 갱신하면, 실행 중 워커의 장전이 이미 신선한 스탬프로 판정돼 차단 실측이 무력화됩니다. Phase 5에서는 워커가 PASS 추기로 재장전해 우회했지만, 스탬프 비교를 세션 스코프 단위로 좁힐지 검토가 필요합니다.
7. **tdd-guard Green 증거의 ANSI 이스케이프 혼입** (Phase 5 관찰) — `tdd-guard.state.json`의 lastGreen.evidence에 vitest의 색상 제어 문자가 그대로 박혀 상태 파일의 사람 가독성이 나쁩니다. 채집 시 제어 문자를 벗기는 정리가 후보입니다.
8. **README 67행의 평문 문서 목록이 옛 편제** (Phase 6 관찰) — 링크가 아니라 검증 스크립트에 잡히지 않지만, PRD·ARCHITECTURE·ADR·UI라는 옛 문서 이름을 평문으로 나열하고 있어 현재 편제와 어긋납니다. 문구 갱신이 후보입니다.
9. **위험 명령 가드의 우회면 확대 수리** (마감 검수 이관, [USER] 2026-08-10) — 재귀 삭제의 긴 플래그·후치 플래그(`rm -R`·`--recursive`·`rm dist -rf`), 플래그 인용(`git reset "--hard"`), `git.exe`·대문자 `Git` 머리 토큰, `git branch --delete --force` 동치, `git stash drop`·`clear` 무규칙, `git checkout .`이 전부 무판정 통과합니다. 이 중 rm 플래그와 인용 우회는 Moodie 원본이 잡던 표면이라 회귀입니다. 3번(인용부 드롭)과 뿌리를 공유하며, 검수 발견 중 우선순위가 가장 높습니다.
10. **가드 주변 정비 묶음** (마감 검수 이관) — 가드만 hook-log에 판정을 남기지 않는 로그 공백, settings의 matcher가 비앵커 `"Bash"`라 다른 훅과 규약이 갈리는 것, 읽기 전용 `git config --global --get`까지 차단하는 오탐 한 건입니다.
11. **tdd-guard의 증거 강도 결함** (마감 검수 이관) — 단건 vitest 통과도 전체 Green 증거로 채집하고(fail-open), 훅 자체를 고칠 때 `.claude/hooks/*.test.mjs`를 동반 테스트로 인정하지 않아 하네스 수리 작업에서 자충수가 됩니다.
